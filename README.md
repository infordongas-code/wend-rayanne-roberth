# Meu Portfólio — HTML, CSS e JavaScript

Projeto simples e responsivo para abrir e editar no Visual Studio Code.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta `portfolio_vscode` no VS Code.
3. Abra `index.html` no navegador. Se tiver a extensão **Live Server**, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Personalização
- No arquivo `index.html`, troque `Seu Nome` pelo seu nome.
- Atualize a seção “Sobre mim”, habilidades, projetos e informações de contato.
- As cores, fontes e layout podem ser editados em `style.css`.
- As interações ficam em `script.js`.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos `index.html`, `style.css`, `script.js` e `README.md` para o repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione a publicação a partir da branch `main` e da pasta `/ (root)`, depois salve.
5. Aguarde a publicação e abra o endereço que o GitHub Pages mostrar.

Observação: o formulário de contato demonstra validação e cópia da mensagem; ele não envia e-mails automaticamente.
